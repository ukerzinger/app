# Journey of Money · PWA

## Sofort lokal ansehen
### Windows
1. Ordner entpacken.
2. `START_LOCAL.bat` doppelklicken.
3. Im Browser `http://localhost:8080` öffnen.

### Mac
1. Ordner entpacken.
2. Terminal im Ordner öffnen.
3. `python3 -m http.server 8080` ausführen.
4. Im Browser `http://localhost:8080` öffnen.

Direktes Doppelklicken auf `index.html` zeigt die App ebenfalls, aber Service Worker / echte PWA-Installation funktionieren nur über HTTPS oder localhost.

## Als echte installierbare App
Lade den kompletten Ordner zu einem statischen HTTPS-Host wie Netlify, Vercel oder GitHub Pages hoch.

Danach:
- Android / Chrome: Installieren-Button bzw. „App installieren“.
- iPhone / Safari: Teilen → „Zum Home-Bildschirm“.
- Desktop Chrome/Edge: Installationssymbol in der Adressleiste.
